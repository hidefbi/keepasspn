KeePassPN lets you open and edit KeePass databases in the KDBX format. It is a fork of KeePassDX and keeps the same database management and autofill workflow. Your database stays wherever you choose to store it, either on your device or in a folder provided by a document provider.

What KeePassPN adds to KeePassDX

1. Quick unlock with a PIN
After you unlock a database with the master password for the first time, the app asks whether you want to set a PIN of at least six digits. With a PIN, you can unlock the database without typing the master password each time.
- The PIN is never stored in plain text.
- The PIN protects an encrypted copy of your master password. A key stored in the Android Keystore is also required to decrypt it.
- After three incorrect PIN attempts, the PIN is deleted and you must enter the master password again. If you then enter the master password incorrectly twice more, the database is removed from the app.
- You can choose how long the PIN stays valid: 7, 14, 30 or 60 days, or indefinitely.
- If you do not open the app within the selected period, the PIN and the app's copy of the database are deleted.
- You can change or disable the PIN under Settings, Device unlock.
Your original .kdbx file is not modified when the app's data is deleted, formatted or cleared.

2. Verify your identity before copying protected fields
When you copy a protected field, the app asks you to verify your identity. The method is chosen in this order: the database PIN if you have set one, otherwise the device screen lock if the device has one, otherwise the first four characters of the master password. You can turn this off under Settings, User Verification.

3. Database recovery copies
Each time a database opens successfully, the app saves a private copy in its own storage. If the original file is replaced with an older version, the app keeps the newer changes from its private copy. If both copies have changed, the app loads the original and saves the private copy as a separate conflict file. This helps preserve your newest changes when a database file is overwritten by an older version.

4. Copy TOTP codes after autofill (optional)
When an autofilled entry contains a time-based one-time password (TOTP), the app can also copy the current code to your clipboard. This setting is optional and does not change how autofill works.

5. One-time codes (2FA)
Open Verification codes to see the current TOTP codes of entries from all groups in one list. Tap a code to copy it. To import, tap the scan button in a group, or Import codes on the Verification codes screen, then scan the batch QR code that Google Authenticator generates when you export accounts, or a single otpauth:// QR code. Imported accounts are saved to a group named 2FA. Accounts that already exist, with the same issuer, name and secret, are skipped. All QR decoding happens on your device. The app does not save camera images and does not request internet access.

6. Privacy
Android cloud backup is disabled for the app, so its data is not included in Android cloud backups.

Features inherited from KeePassDX
Opening KDBX databases from local storage or a document provider, the Android Autofill service, and passkey provider support for Android Credential Manager.

Things to know before enabling PIN unlock
A PIN is much less secure than a sufficiently long master password. The failed-attempt counter is stored by the app itself, so an attacker with root access to the device may be able to reset it. Enable PIN unlock only if you accept these risks.
